Details of all the python scripts in my Repository:
===================================================================================================================================================================================================================
1. import_pdf-tables_toCSV.py >>> Converts all the tables of entire pdf document having multiple pages to the new CSV file with single table.
2. list_allfiles_in_Dir.py >>> Lists all the files of the required directories(need to explicitly mention the path of the single or multiple directories in the script) in the new text file.
3. search_listofwords_fetchthematchinglist.py >>> Contents stored in the first file(here, list_of_words.txt) is searched in the second file(here, master_file.txt). Once the contents of the first file matches in the second file, it fetches that particular line from the second file and stores to the new file. Useful to fetch the difference or similarity by explicitly mentioning the content in the first file which works as input file to the master file(2nd file).
